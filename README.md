# eTOPSIS - Исследовательский прототип расширенного метода TOPSIS

## О проекте (About)

*Research prototype of the Extended TOPSIS method for analyzing and comparing group decision-making approaches.*

Исследовательский прототип реализации расширенного метода TOPSIS (eTOPSIS) для анализа и сравнения подходов к групповому принятию решений.

Проект реализован во время подготовки Алекандры С. Носковой работы в рамках тестирования программного обеспечения в Институте компьютерных наук и кибербезопасности СПбПУ (ИКНК СПбПУ).

Метод основан на статье: Yue Z. "A method for group decision-making based on determining weights of decision makers using TOPSIS" // Applied Mathematical Modelling. – 2011. – Vol. 35, no. 4. – P. 1926–1936. – DOI: 10.1016/j.apm.2010.11.001.

## Структура проекта (Project Structure)
- research/ - директория с материалами исследования.
  - testing_data/ – тестовые наборы данных (testing data), созданные для проверки и демонстрации работы метода. Включают три примера (см. ниже).
  - analysis/ – результаты проведения вычислительных экспериментов. 
- prototype/ – код прототипа реализации алгоритма eTOPSIS.
- docs/ – дополнительная документация по алгоритму.

## Краткое описание примеров и результатов (Examples Overview)
В репозитории представлены следующие тестовые наборы данных (testing data), расположенные в research/testing_data/:
1. **example1.json**: Контрольный пример из исходной научной статьи Yue Z. (2011). Используется для верификации и проверки корректности реализации алгоритма.
2. **example2.json**: Упрощенный пример выбора смартфона. Демонстрирует базовый принцип работы метода на интуитивно понятной задаче с небольшим числом альтернатив и критериев.
3. **example3.json**: Основной практический пример выбора оптимального датасета для задачи SQL-to-text. Иллюстрирует применение метода для агрегирования результатов множества различных методов оптимизации (Парето, лексикографический и др.) в единое групповое решение. В результате ранжирования наивысший приоритет получает датасет **_Spider_**.

## Быстрый старт
Варианты использования скрипта для eTOPSIS:
```bash
python prototype/run_example.py   # запустит example1 по умолчанию.
```
```bash
python prototype/run_example.py example2   # запустит пример выбора смартфона (example2).
```
```bash
python prototype/run_example.py example3   # запустит основной пример выбора датасета (example3).
```

### Установка зависимостей
```bash
pip install -r prototype/requirements.txt
```
